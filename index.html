About

A review taxonomy made inspectable and reusable

The atlas turns the review's conceptual axes into a living, searchable resource for choosing multimodal integration methods. Each entry is classified against the same taxonomy, linked to primary literature and software where available, and maintained as a transparent table that can grow with community curation.

The revised review framework

Axes for method choice

Begin with the available measurements and required output. Then refine model design, learning setup and practical requirements. Methodological building blocks can overlap.

Capabilities refer to documented workflows. An unpaired application may require a model trained on paired data. Biological/technical separation is not the same as shared/private modality decomposition; predictive uncertainty is not automatically calibrated.
